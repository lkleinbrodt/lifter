# Lifter

Personal lifting app (Expo / React Native, iOS-first) with two programs: 5/3/1 and Greyskull LP.

- `npm install`, then `npm start` for the dev server.
- `npm run update:ota -- "what changed"` publishes a JS-only update to the installed build.
- `npm run release:ios` builds and installs a Release build on the iPhone (Mac only).

See `MOBILE.md` for the install/update workflow and `CLAUDE.md` for architecture and conventions.
